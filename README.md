# Speech Recognition Coursework Projects

This repository contains two independent Python projects related to acoustics and speech processing:

- [`sound-propagation-analysis/`](sound-propagation-analysis/) — analyzes measured sound levels over distance and converts sound pressure level (dB SPL) to pressure in pascals.
- [`speech-emotion-speaker-recognition/`](speech-emotion-speaker-recognition/) — extracts acoustic features from RAVDESS audio, compares emotion classifiers, identifies speakers, and serves predictions through Streamlit.

Each project has its own README with setup instructions, verified results, limitations, and notes for later resume evaluation.
